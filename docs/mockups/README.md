# Bản mẫu giao diện

File tự chứa, mở thẳng bằng trình duyệt, không cần chạy server.

`build-lab.html` — bàn thử build: cặp chỉ huy, bộ lọc tìm chỉ huy (độ hiếm /
loại đơn vị / bối cảnh), cây tài năng, bảng nâng cấp kỹ năng, bảy ô trang bị có
bậc I–V và minh văn, bốn ô vũ trang, và bảng chỉ số cộng theo thời gian thực.

Mọi con số trong file là dữ liệu bịa để dựng bố cục. Tên chỉ huy là tên tạm — số
`#182` dưới mỗi ảnh là id ảnh trong game (xem `content/armory/ASSETS.md`).

Đây là bản để nhìn và sửa bố cục, không phải mã sẽ chạy trên trang. Khi dựng
thật, dùng biểu tượng ở `public/game/` thay vì ảnh nhúng base64 trong file này.
